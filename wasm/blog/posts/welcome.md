Welcome! Every page you see was rendered from Markdown on your own machine
by [MD4C](https://github.com/mity/md4c), compiled to WebAssembly. The server
only stores the Markdown files.

## What you can do

- [x] Read the sample posts
- [ ] Log in as the admin (link in the footer)
- [ ] Write a draft, watch the live preview, then publish it

Anyone can read published posts; only the blog owner can write, publish and
delete them. To learn how the pieces fit together, read
[[How it works]]. To see what the renderer supports, open the
[[Markdown showcase]].

> [!TIP]
> Drafts stay private to the admin until they are published.
