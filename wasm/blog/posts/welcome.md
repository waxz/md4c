Welcome! Every page you see was rendered from Markdown on your own machine
by [MD4C](https://github.com/mity/md4c), compiled to WebAssembly. There is
no server code at all: the posts are plain files in read-only storage.

## What you can do

- [x] Read the sample posts
- [ ] Follow a tag
- [ ] Jump between posts with wiki links

Anyone can read; only the blog owner, who holds the storage credentials,
can publish. To learn how the pieces fit together, read
[[How it works]]. To see what the renderer supports, open the
[[Markdown showcase]].

> [!TIP]
> Drafts never leave the owner's machine: the publish script skips them.
